# Reel edit (Remotion)

A premium Instagram-reel editing system: gradient colour-palette transitions,
After Effects-style kinetic typography, SaaS/UI motion graphics, word-by-word
captions and a synthesized sound-design kit. The pacing follows the Iman Gadzhi
/ Joseph Video Editing school: punch-ins on every sentence, a hook in the first
second, chapter cards, statement slams, and sound on every visual hit.

**The edit never changes the footage's format.** The `Reel` composition reads
the source video and inherits its exact width, height, fps and duration, and
every overlay scales from a 1080×1920 design to whatever the footage is.

## Quick start

```bash
cd reel
npm i
npm run standin        # renders the placeholder footage the demo uses
npm run dev            # Remotion Studio: open "StyleDemo" or "Reel"
npm run render:demo    # -> out/style-demo.mp4
```

## Editing your own video

1. Put the footage at `public/input.mp4` (any aspect ratio).
2. `npm run transcribe` writes word-level captions to `public/captions.json`
   (whisper.cpp; set `WHISPER_LANG=fr` for French, `WHISPER_MODEL` to change size).
3. Cut it in `src/edits/MainEdit.tsx`, the same way `src/edits/StyleDemo.tsx` is cut:
   - `shots`: punch-ins (`scale`, `x`, `y`) on sentence boundaries, `smooth` for eased zooms
   - `transitions`: `sweep` / `bars` / `iris` / `flash` at section changes; the cut sits at `at`
   - `<Beat>`s for headlines, keyword slams and UI cards on the words they illustrate
   - `<Sfx>` for extra hits (transitions already carry their own whooshes)
4. `npm run render` -> `out/reel-edited.mp4` (H.264, CRF 16, AAC; ready for Instagram).

## Toolkit

| Layer | Component | What it does |
| --- | --- | --- |
| Footage | `CameraRig` | Punch-ins, slow push, zoom-blur kicks on transitions, impact shake |
| Footage | `Finish` | Vignette, caption scrim, animated film grain |
| Transition | `GradientSweep` | Layered palette bands cascade in, optional chapter card, peel out |
| Transition | `PrismBars` | Pill-shaped gradient columns rise into a wall and exit upward |
| Transition | `IrisBloom` | Concentric gradient rings bloom, then ripple open from the centre |
| Transition | `GlowFlash` | Screen-blended gradient orbs: a soft dip to light |
| Text | `KineticHeadline` | Masked word rise + blur resolve, `*emphasis*` in gradient serif italic with drawn underline |
| Text | `KeywordSlam` | Monochrome dim, one huge word slams in with a breathing aura |
| Text | `Captions` | Word-by-word, active word on a gradient pill, keywords in gradient serif |
| UI | `Toast`, `StatCard`, `SearchBar`, `Cursor`, `Checklist` | Glassmorphism SaaS UI with springy motion |

Palettes live in `src/theme.ts` (`aurora`, `ocean`, `sunset`, `mint`, `royal`).
Sound effects are generated by `npm run sfx` (`scripts/make-sfx.py`, numpy) into
`public/sfx`. Fonts are Inter and Instrument Serif (SIL OFL), bundled in
`public/fonts`.

## Rendering in a sandbox without Chrome downloads

Set `REMOTION_BROWSER_EXECUTABLE` to a local Chromium / headless shell and
Remotion will use it instead of downloading one.
